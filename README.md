# DinoPedia - A Manifest-Powered Dinosaur Encyclopedia

Welcome to DinoPedia, a full-stack React application for cataloging and exploring dinosaurs. This application is powered entirely by the Manifest backend, demonstrating user authentication, data relationships, and role-based permissions.

## Features

- **User Authentication**: Sign up, log in, and manage your account.
- **Dinosaur Catalog**: View a list of dinosaurs with images and details, managed by administrators.
- **Log Sightings**: Authenticated users can log personal 'sightings' of dinosaurs.
- **Ownership Policies**: Users can only view and manage their own sightings.
- **Admin Panel**: A complete, auto-generated admin interface to manage all dinosaurs, users, and sightings.

## Getting Started

### Prerequisites

- Node.js and npm
- A Manifest project (this app is designed to run within one)

### Installation

1.  **Clone the repository** (or use the files generated by the platform).
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Run the development server**:
    ```bash
    npm run dev
    ```
    The application will be available at `http://localhost:5173`.

### Accessing the Admin Panel

The Manifest backend automatically provides a powerful admin panel.

-   **URL**: Accessible via the 'Admin Panel' link in the app.
-   **Default Admin Credentials**:
    -   Email: `admin@manifest.build`
    -   Password: `admin`
-   **Default User Credentials**:
    -   Email: `user@manifest.build`
    -   Password: `password`

Use the admin panel to add dinosaurs to the catalog so they appear in the main application.
